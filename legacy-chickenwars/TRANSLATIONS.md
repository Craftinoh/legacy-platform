# Stato traduzioni ChickenWars

ChickenWars supporta gli stessi 31 codici lingua di NetworkLanguage.

I cataloghi `messages_it.yml` e `messages_en.yml` sono le versioni curate.
I restanti cataloghi vengono inizializzati con il contenuto inglese completo,
così ogni lingua dispone di tutte le chiavi e il plugin non mostra messaggi
mancanti. Possono essere tradotti progressivamente senza cambiare codice.

All'avvio `TranslationInstaller` copia i cataloghi mancanti nella cartella
`plugins/LegacyChickenWars/translations` senza sovrascrivere i file già
personalizzati dall'amministratore.
